## העלאה לאוויר ב-Vercel — חינם (כ-5 דקות)

התוכנית החינמית של Vercel (Hobby), יחד עם מסד הנתונים החינמי של Neon, מספיקות למשרד שלם.

1. נכנסים ל-[vercel.com/new](https://vercel.com/new) עם חשבון GitHub ← **Import** ליד `israelections`.
   - הגדרות ה-build נטענות מ-`vercel.json` — לא משנים כלום.
   - ב-**Environment Variables** מוסיפים `ADMIN_EMAILS` = המייל שלך.
   - לוחצים **Deploy**.
2. **מחברים מסד נתונים (חובה):** בפרויקט ← לשונית **Storage** ← **Create Database** ← **Neon** (Serverless Postgres).
   - תוכנית **Free**, אזור **Frankfurt (eu-central-1)** — קרוב לשרת, שמוגדר בפרנקפורט.
   - **Connect** לכל הסביבות. החיבור מוסיף את `DATABASE_URL` לבד.
3. **Deployments** ← בשלוש הנקודות של הפריסה האחרונה ← **Redeploy**, כדי שהחיבור למסד ייכנס לתוקף.
4. פותחים את הכתובת `…vercel.app` ונכנסים ראשונים עם המייל מ-`ADMIN_EMAILS`, פותחים ליגה למשרד ושולחים את קישור ההזמנה. התוצאות מוזנות ב**אני ← ניהול האתר**.

> **ענף:** Vercel פורס לפרודקשן את ענף ברירת המחדל של הריפו. אם הקוד נמצא בענף אחר: **Settings → Git → Production Branch**.
>
> **אם רואים ״חסר חיבור למסד נתונים״** — שלב 2 או 3 לא הושלם.

משתני סביבה נוספים (אופציונליים):

| משתנה | מה עושה |
|---|---|
| `ALLOWED_EMAIL_DOMAINS` | רק מיילים מהדומיין הזה יוכלו להיכנס (למשל `company.co.il`) |
| `VAPID_EMAIL` | מייל ליצירת קשר עבור שירותי הפוש |

**תזכורות לפני נעילה:** אין שרת שרץ ברקע ב-Vercel, אז התזכורות נשלחות כשמישהו פותח את האפליקציה בחלון הזמן (מספיק משתמש אחד, וזה קורה כל הזמן ביום בחירות). כל תזכורת נשלחת פעם אחת בלבד. כדי שיגיעו בדיוק בזמן גם כשאין תנועה, אפשר להגדיר ב-[cron-job.org](https://cron-job.org) (חינם) קריאה כל 5 דקות ל-`https://<הכתובת>/api/cron`.

### פריסה במקום אחר
יש `Dockerfile`. בלי `DATABASE_URL` המידע נשמר ב-Postgres מוטמע (PGlite) תחת `/data`, אז צריך לחבר לשם volume. אם רוצים מסד חיצוני — מגדירים `DATABASE_URL`.

## פיתוח

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # בדיקות למנוע הניקוד
```

- **שרת:** Node 22 ו-Express — כפונקציה ב-Vercel (`api/index.js`) או כשרת רגיל (`server/index.js`).
- **מסד נתונים:** Postgres. בפרודקשן Neon, ובפיתוח מקומי PGlite מוטמע תחת `data/`, בלי התקנה.
- **פוש:** Web Push עם VAPID. המפתחות נוצרים אוטומטית ונשמרים במסד הנתונים.
- **לקוח:** Preact ו-htm בלי שלב build (הקבצים ב-`public/vendor`, מתעדכנים עם `npm run vendor`), כ-PWA בעברית עם תמיכה ב-RTL ובמצב כהה.
- **נתוני הסקרים:** ממוצע הסקרים האחרונים של כאן 11, חדשות 12 וחדשות 13 (23.10.2026). מעדכנים ב-`PARTIES` שב-`public/shared/game.js`.

## העלאה לאוויר (Railway, כ-10 דקות)

1. נכנסים ל-[railway.com](https://railway.com) ← **New Project** ← **Deploy from GitHub repo** ← בוחרים את `israelections`.
   אם הקוד עוד לא מוזג ל-`main`: בהגדרות השירות (**Settings → Source**) בוחרים את הענף `claude/peaceful-brown-rqqbvu`.
2. **חובה – אחסון קבוע:** לוחצים על השירות ← **Add Volume** (או קליק ימני ← Attach volume) ← Mount path: `/data`.
   בלי זה כל ההימורים יימחקו בכל פריסה מחדש.
3. **Variables** – מוסיפים:
   | משתנה | ערך | חובה? |
   |---|---|---|
   | `ADMIN_EMAILS` | המייל שלך (אפשר כמה, מופרדים בפסיק) | מומלץ מאוד |
   | `ALLOWED_EMAIL_DOMAINS` | הדומיין של העבודה, למשל `company.co.il` — רק מיילים ממנו יוכלו להיכנס | אופציונלי |
   | `VAPID_EMAIL` | מייל ליצירת קשר עבור שירותי הפוש | אופציונלי |
4. **Settings → Networking → Generate Domain** — זה הקישור ששולחים למשרד.
5. נכנסים ראשונים עם המייל שהגדרתם ב-`ADMIN_EMAILS` — בלשונית **אני ← ניהול המשחק** יש את פאנל הניהול.

> אם לא מגדירים `ADMIN_EMAILS`, המשתמש הראשון שנרשם הופך למנהל.

### פריסה במקום אחר
יש `Dockerfile`. כל מה שצריך: לחבר volume לנתיב `/data` ולהעביר את משתני הסביבה. השרת מאזין ל-`PORT` (ברירת מחדל 3000).

## כניסה למשחק

**ברירת המחדל – מייל + קוד אישי בן 4 ספרות.** בכניסה הראשונה בוחרים קוד, ובפעמים הבאות (למשל מהטלפון) מקלידים אותו. שכחו? מנהל/ת המשחק מאפס/ת אותו בפאנל.

**אופציונלי – קוד חד-פעמי שנשלח למייל.** מגדירים אחד מאלה ובנוסף `MAIL_FROM` (למשל `61 <elections@company.co.il>`):

| שירות | משתנים | הערות |
|---|---|---|
| [Resend](https://resend.com) | `RESEND_API_KEY` | צריך לאמת דומיין כדי לשלוח לאחרים |
| [Brevo](https://brevo.com) | `BREVO_API_KEY` | 300 מיילים ביום בחינם, מספיק לאמת כתובת שולח אחת |
| SMTP של החברה | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | ⚠️ ב-Railway (תוכנית Hobby) פורטי SMTP חסומים — שם עדיף Resend/Brevo |

## התראות לטלפון

- **אנדרואיד / מחשב:** לוחצים ״הפעלה״ בכרטיס ההתראות.
- **אייפון:** קודם מוסיפים את האתר למסך הבית (כפתור השיתוף ⬆︎ ← ״הוספה למסך הבית״), פותחים משם ומפעילים התראות (iOS 16.4 ומעלה). האפליקציה מסבירה את זה למשתמשים.

התראות שנשלחות אוטומטית:
- תזכורת 3 שעות וחצי שעה לפני נעילה, רק למי שעוד לא סיים.
- תזכורת לשאלת אחוז ההצבעה.
- עדכון אישי עם המקום בטבלה בכל פעם שמזינים תוצאות.
- פתיחת שלב ב׳.

מפאנל הניהול אפשר גם לשלוח הודעה חופשית לכולם.

## פיתוח

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # בדיקות למנוע הניקוד
```

- **שרת:** Node 22, Express ו-SQLite (`node:sqlite`, בלי תלויות נייטיב).
- **פוש:** Web Push עם VAPID. המפתחות נוצרים אוטומטית ונשמרים במסד הנתונים.
- **לקוח:** Preact ו-htm בלי שלב build, כ-PWA בעברית עם תמיכה ב-RTL ובמצב כהה.
- **נתוני הסקרים:** ממוצע הסקרים האחרונים של כאן 11, חדשות 12 וחדשות 13 (23.10.2026). מעדכנים ב-`PARTIES` שב-`shared/game.js`.
